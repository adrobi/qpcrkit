# Demo data

Two Bio-Rad CFX "Quantification Cq Results" exports generated by
`scripts/make_demo.py` (fixed seed): IL6 (target) and GAPDH (reference),
groups `Ctrl`, `LPS`, `LPS+Dex` × 3 biological × 3 technical replicates,
inter-run calibrators (`IRC`) on both plates, IL6 standards 10–10⁵ copies on
plate 1, NTCs on both. Plate 2 runs 0.5 cycles later than plate 1.

```bash
qpcrkit new examples/demo_run1.csv examples/demo_run2.csv --ref GAPDH --control Ctrl -o demo.qpcrkit.json
qpcrkit analyze demo.qpcrkit.json -o results.xlsx --html report.html --figures figures/
```

Expected: IL6 ≈ 8× up in `LPS`, ≈ 2× in `LPS+Dex`.
